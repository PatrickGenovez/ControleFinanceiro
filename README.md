Desenvolvi um sistema de Controle Financeiro em Java como parte da minha jornada de aprendizado em desenvolvimento back-end.

O projeto foi dividido em duas fases:

▸ Fase 1 — JDBC Puro: conexão com MySQL utilizando "DriverManager", consultas com "PreparedStatement" e manipulação de resultados com "ResultSet".

▸ Fase 2 — Spring Boot + JPA:** migração para Spring Boot 3, Spring Data JPA e Hibernate, aplicando mapeamento de entidades, repositórios e injeção de dependências.

   Conceitos aplicados:
- Arquitetura em camadas (Model, Service e Repository).
- BigDecimal para operações financeiras.
- Validação de regras de negócio.

    Desenvolvimento com apoio de IA:
Durante o desenvolvimento, utilizei uma IA como ferramenta de aprendizado. Eu escrevia o código e recorria a ela quando surgiam dúvidas, buscando entender os conceitos e as soluções aplicadas.

Tecnologias: Java 21 · Spring Boot 3 · Spring Data JPA · Hibernate · MySQL · Maven

Próximos passos: API REST com Controllers e DTOs, histórico de transações e documentação com Swagger/OpenAPI.
